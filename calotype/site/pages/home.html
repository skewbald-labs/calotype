For agents: working in one minute

Make a free key, add one server to your agent, then ask it about a page. In Claude Code:

curl -s -X POST https://calotype.dev/v1/keys      # copy "key" from the answer
claude mcp add --transport http calotype https://calotype.dev/mcp \
  --header "Authorization: Bearer cal_..."

Then ask the agent:

Take a dark-mode screenshot of https://calotype.dev/pricing and tell me the Starter price.

The price is on the rendered page, so a right answer means the agent saw it. An agent can run the first line itself: making a key needs no email and no human. Cursor, VS Code, Codex and other clients are on the For agents page.

Why a hosted browser

  • Your agent has no browser. Cloud coding agents, agent backends and sandboxes often cannot download or run Chromium. Calotype runs it for them.
  • The browser stays off your network. An agent can be talked into fetching any address, including your internal ones. A May 2026 advisory reported this server-side request forgery risk in widely used fetch and browser MCP servers that run next to the agent. Calotype's browser runs on Calotype's servers, and it refuses private, loopback and cloud-metadata addresses on every request, redirect and sub-request.
  • It protects your network, not your model. A screenshot still carries the page's text to the model, so a hostile page can still try prompt injection. Treat what a page says as data, not instructions.

What it does not do

  • Public pages only. Calotype cannot see localhost, a private preview or anything behind a login. For a local dev server, use a browser that runs on your machine, such as Playwright MCP.
  • Sandboxes may need a rule. If your agent's sandbox limits outbound traffic, allow calotype.dev.
  • One look, not a session. No clicking, typing or scrolling: one address in, one image out.

For developers: the HTTP API

The same capture from any language, with no MCP client. PNG, JPEG or WebP, any viewport up to 4K, full page, dark mode, ad blocking:

curl -H "Authorization: Bearer $CALOTYPE_KEY" \
  "https://calotype.dev/v1/screenshot?url=https://example.com&width=1280&height=800" \
  -o example.png

The image comes back as the response body. The header X-Calotype-Usage shows this month's count, for example 12/100. Every parameter, error and limit is in the API reference.
